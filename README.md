# 영어 발음 연습장

단어나 문장을 쓰면 미국식 발음으로 읽어 주는 영어 공부 페이지예요.
👉 https://shgudtn1-byte.github.io/english-practice/

- 🔊 미국식 발음 듣기 (보통 / 천천히 / 아주 천천히 / 한 단어씩)
- 📷 낱말마다 이모지와 사진(위키백과 대표 사진 + Openverse CC 사진, 성인물 제외)
- 📗 국어사전: 모르는 우리말 낱말을 초등 1학년이 알아듣는 말로 풀이 (비슷한 말·반대말·영어 단어)
- 👶 영어 뜻도 1학년용 쉬운 설명과 쉬운 예문으로 (Oxford 사전은 '더 자세히'에)
- 📚 품사별 한국어 뜻 + Oxford 영어 뜻 + 예문
- ✍️ 배운 단어 넣기 (하나씩 / 한꺼번에), 배운 곳별로 묶기
- 🇰🇷 한국말로 쓰면 자연스러운 영어 문장으로 바꿔 주기 (쉬움/보통 표시, 다르게 말하기, 단어 뜻)
- 🗣️ 문장 시험: 🧠 외우기(빈칸 늘리기) · 🧩 순서 맞추기 · ⌨️ 영어로 쓰기
- 🎤 소리 내어 말하기: 발음(음성 인식으로 단어별 확인)과 억양(목소리 높이·문장 끝 올림/내림·빠르기)을 %로 알려 주기
- ✍️ 어디서든 "써 보기" 버튼으로 소리 듣고 스펠링 쓰기
- 📝 뜻 시험, ✏️ 받아쓰기 — 처음부터 배운 모든 단어에서, 자주 틀린 단어가 더 자주 나와요
- ☁️ 단어장은 이 저장소의 `data/words.json`에 저장돼서 여러 컴퓨터에서 같이 써요

뜻·예문: Oxford Languages (Google 사전), 번역: Google 번역, 쉬운 예문: Tatoeba (CC BY 2.0 FR)

📱 아이폰: Safari로 열고 공유 → 홈 화면에 추가하면 앱처럼 쓸 수 있어요 (처음 한 번 ☁️ 연결 키 넣기).
