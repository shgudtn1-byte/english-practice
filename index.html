☁️ 여러 컴퓨터에서 같은 단어장 쓰기

단어장은 GitHub 저장소 shgudtn1-byte/english-practice의 data/words.json에 계속 저장돼요. 어느 컴퓨터에서든 단어 보기와 시험은 바로 되고, 새 단어와 시험 결과를 저장하려면 그 컴퓨터에서 한 번만 연결하면 돼요.

  1. GitHub 연결 키 만들기 페이지를 열어요 (부모님 GitHub 계정)
  2. Token name: english-practice · Expiration: 원하는 기간 (예: 1년)
  3. Repository access → Only select repositories → english-practice
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token을 누르고 나온 github_pat_… 글자를 복사해 아래에 붙여 넣어요

연결 키는 이 컴퓨터의 브라우저에만 저장되고, 이 저장소 하나에만 쓸 수 있어요. 저장소가 공개라서 단어 목록은 다른 사람도 볼 수 있어요.
